## Ticket 3 — Unknown URLs return 200 with homepage content (soft 404)

**Traffic at stake: 0 sessions today — structural index-quality risk, not a traffic loss**

- **URL**: any nonexistent path, e.g. https://baselayerskin.co/this-page-does-not-exist-xyz → HTTP 200, homepage `<title>`, no canonical
- **Problem**: the SPA fallback (`public/_redirects` last line: `/* /index.html 200`) serves the prerendered homepage shell for every unknown URL. Google classifies these as soft 404s; any typo'd inbound link mints an indexable homepage duplicate and wastes the crawl budget of a site already struggling to get crawled.
- **Exact fix**: the site is fully prerendered (every real route has a static file in `dist/`), so the fallback only ever catches genuinely unknown paths. Prerender the existing NotFound page to `dist/404.html` in the build step, then change the last line of `public/_redirects` to:
  ```
  /*    /404.html   404
  ```
  **Pre-ship check**: confirm no client-only routes rely on the index.html fallback (e.g. cart/checkout interstitials — Shopify paths are already handled by explicit 301s above the fallback).
